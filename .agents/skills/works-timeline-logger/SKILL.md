# Works Timeline Logger

บังคับใช้เมื่อมีการแก้ไขหรือเขียนโค้ดในโปรเจกต์ เพื่อให้ AI ตัวอื่นที่มาทำงานต่อเข้าใจบริบททันทีว่างานทำถึงไหนแล้ว

## ขั้นตอน
1. **ตั้งชื่อไฟล์ตามวันที่ปัจจุบัน (`DD-MM-YYYY.md`):** เช่น `works-time-line/29-10-2026.md`
   - หากยังไม่มีโฟลเดอร์หรือไฟล์ของวันนั้น ให้ **สร้างใหม่**
   - หากมีไฟล์ของวันนั้นอยู่แล้ว ให้ **เพิ่มหัวข้อต่อท้าย** ในไฟล์เดิม ห้ามเขียนทับ
2. **เขียนเนื้อหาสรุปให้กระชับ ชัดเจน สำหรับ AI ตัวถัดไป:**
   - **สิ่งที่ทำเสร็จแล้ว (Completed):** แก้ไข/พัฒนาส่วนไหน (เช่น Schema, Backend API, Frontend UI, Component), เชื่อมต่อ API อะไร, ไฟล์สำคัญที่เปลี่ยน และเหตุผลหลัก
   - **สถานะปัจจุบัน & งานที่ยังค้างอยู่ (Current Status / Next Steps):** ทำถึงไหนแล้ว เหลือจุดไหนที่ยังไม่ได้ทำ และข้อควรระวังที่ AI ตัวถัดไปต้องรู้ (อ้างอิง [`../project-overview.md`](../project-overview.md) เมื่อเหมาะสม)

## ข้อควรระวัง
- ห้ามใส่ secrets, token, credentials หรือข้อมูลอ่อนไหวในบันทึก
- รายงานผล Typecheck/Lint/Tests/Build ตามจริง (`PASS` / `FAIL` / `NOT RUN`) ห้ามอ้างว่าผ่านโดยไม่ได้รัน
